# Projet de détection des chaleurs

Ce dépôt contient les données, les codes R, les analyses et les documents du projet.

Le but du projet est de détecter un changement de comportement chez les brebis à partir des interactions entre les brebis et les béliers.

## Data

Le dossier `Data` contient deux types de données :

- les fichiers Excel, qui sont les données biologiques originales ;
- les fichiers `.rda`, qui sont les données biologiques transformées pour être utilisées dans R.

## R

Le dossier `R` contient les fichiers R avec les fonctions utilisées par les algorithmes.

## Vignettes

Le dossier `Vignettes` contient le fichier principal pour lancer les fonctions dans les fichiers R sur les données.
